## 响应策略待办：IND-006

当前策略是：只要问题存在必要证据缺失，就整体返回拒答。`IND-006` 因项目实际设备尺寸和最终加宽、加高量不在规范中而正确拒答，但响应没有同时说明规范已经支持的原则：应按设备安装位置及尺寸检算建筑限界，必要时采取局部加宽、加高措施。

后续单独设计“部分回答”策略：

1. 先说明证据已经支持的规范原则，并逐项引用。
2. 明确列出无法由现有证据确定的项目实际值。
3. 不把未知项目值补造为规范结论，也不把通用原则误写成项目设计结果。
4. 为完整回答、部分回答、整体拒答和服务错误分别定义外部契约与质量门槛。
5. 使用专门数据覆盖完全支持、部分支持、完全不支持和服务故障，不以单个 `IND-006` 调整提示词。

该待办属于产品响应策略和评测设计，不继续修改 Grader 来追求 `IND-006` 的表面通过，也不纳入当前单规范修复基线。
