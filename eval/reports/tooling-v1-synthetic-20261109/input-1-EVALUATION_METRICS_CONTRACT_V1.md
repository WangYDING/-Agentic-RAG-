# 评测指标与评分口径 v1（初稿）

日期：2026-11-09。状态：接口与规则设计稿，尚未接通或验证全部计算脚本，尚未冻结为独立验收规则。只适用于后续新评测，不追溯修改历史数据、报告或门槛。当前目录为历史保全工作区；本文是评测线新增设计，不表示此处代码是最新 RAG 候选。

## 1. 数据与系统隔离

评测端保存题号、题型、问题、查询范围、expected_action（answer/refuse/clarify）、必要事实及编号、参考答案、证据组、数值/单位/条件、审核记录。RAG 只接收问题和查询范围，不接收标准答案、事实清单、证据标签或预期行为。

系统输出 answer/refuse/clarify/error；记录实际范围、按轮次和阶段命名的候选排序、生成器实际接收的上下文、引用、错误码、耗时、模型调用与用量、版本指纹。没有生成调用时，generator_context 为 null；另存最终判定证据，不能冒充生成器上下文。

证据用稳定文档 ID、规范版本、原始 PDF 页码（从1开始）、条文/表格定位，必要时附原文摘录与文件哈希；不以 chunk ID 作为唯一 gold。每个事实允许多个证据方案，方案内部要求同时满足，方案之间满足任意一个即可；等价方案须在独立运行前审核并冻结。位置匹配与事实语义支持分别评分。

## 2. 指标定义

A 为预期回答题数，R 为预期拒答题数，C 为预期澄清题数，N=A+R+C。每项同时输出分子、分母、率和适用题号；分母为0时为 null。K 固定取1、3、5、10；不足K条不补结果。

| 指标 | 定义与分母 | 判断方式 |
|---|---|---|
| Recall@K | 每个回答题：前K结果覆盖的必要证据组数/该题全部必要证据组数，再对A题取宏平均；微平均另名报告 | 自动位置匹配 |
| HitRate@K | 前K至少命中一个必要证据组的回答题数/A | 自动位置匹配 |
| MRR@10 | 对A题平均首个相关结果名次的倒数；前10无命中记0 | 自动位置匹配 |
| 最终事实完整覆盖率 | 最终判定证据支持全部必要事实及条件的回答题数/A | 逐事实复核 |
| 完整正确答案率 | 最终为answer，覆盖全部必要事实、数值单位条件正确、无矛盾及证据外实质性结论，且引用合法且支持结论的题数/A | 自动检查+答案复核 |
| 证据支持度 | 对已生成回答的回答题逐项标注实质性事实主张为supported/unsupported/contradicted；每题supported数/主张总数，再取宏平均 | 主张级复核 |
| 错误接受率 | 预期refuse但实际answer的题数/R | 自动 |
| 错误拒答率 | 预期answer但实际refuse的题数/A | 自动 |
| 澄清行为正确率 | 预期clarify且实际clarify的题数/C；澄清内容是否恰当另行复核 | 自动+复核 |
| 引用合法率 | 至少有引用且全部引用编号可解析、来源完整并符合范围的回答数/全部实际answer数 | 自动 |
| 服务错误率 | 实际error题数/N；接口异常与系统故障记录原因，不能计为业务拒答 | 自动 |
| 端到端任务成功率 | 回答题达到完整正确标准、拒答题正确拒答且理由恰当、澄清题正确澄清且内容恰当的题数/N | 自动+复核 |
| 性能 | 每题端到端时长、p50/p95、模型调用次数及token；按预期行为与题型分组，并列成功与错误请求 | 自动 |

候选与重排后列表分别计算检索指标，明确命名，如 initial_candidates、initial_reranked；不把重排后的Recall叫候选召回率。重试轮单独记录。最终条文完整覆盖率作为诊断项保留，不替代最终事实完整覆盖率。

最终判定证据和 generator_context 分开：对所有A题报告前者的事实覆盖；另对实际调用生成器的回答题报告上下文事实覆盖，并披露条件化分母，不能通过拒答难题抬高整体成绩。

证据支持度仅是已回答样本的条件指标，不能替代完整正确答案率。空答案或无实质主张的answer不能获得满分，标为无效回答。refuse/clarify/error保留完整行为混淆矩阵；例如回答题被澄清虽然不算错误拒答，也不能算成功。

性能分位数采用 nearest-rank：排序后取 ceil(p*n) 的第一个基于1的秩。端到端计时从调用系统到收到结果，包含内部重试；初始化/索引准备单独记录，不混入热查询。用量缺失保持null，汇总已观测token并报告观测比例；不得将缺失当0。费用仅在可信费率及币种已记录时估算。

## 3. 复核与完整性

每个必要事实分别记录上下文支持情况、答案覆盖情况、正确性、证据ID和理由；主张支持与数值条件单独记录。未复核为null，不默认为通过。引用解析合法不代表语义支持。主指标定义使用布尔/分类判定；历史0/1/2量表可留作辅助，但不能无说明混算。

复核者记录身份、时间、规则版本；AI辅助审核必须披露，不能写成人工或领域专家签字。最终质量审批仍需人工复核。部分复核只报告已核样本分数、审核进度及全量已确认成功下界，不输出全量最终通过结论。复核争议记录裁决与理由，不静默修改原始输出。

## 4. 冻结与验收

先用旧开发/回归题及模拟输出验证读取、指标、错误处理和报告，不用新独立题调试RAG。新独立题依原文审核，覆盖面与样本数独立记录；不声称少量题能证明广泛泛化。

正式运行前固定代码提交和工作树状态、Prompt/配置、模型标识及可用revision、文档/索引快照、脚本、题集、规则与门槛的版本/哈希。无法固定的服务端模型版本如实记为未知。

本稿不设新的具体数值通过线。硬失败项目拟包含范围/版本越界、非法引用正常返回、关键数值条件错误、证据外核心结论；具体容许数量、质量和延迟门槛在查看新独立结果前单独冻结。服务错误保留且计入运行统计；独立验收结论为未决，是否同版重试及合并方式须预先声明，不能选择性删除失败尝试。

运行完成后先复核再签署pass/fail/inconclusive。评测完成不等于系统达标。根据独立结果调试后，该题集转为已见回归；首次原始成绩永久保留。

## 6. 本轮工具实现补充（未冻结）

评分函数见 `eval/scoring_v1.py`。主指标保持以上口径：微平均另命名；MRR 的相关项是任一固定方案中的证据成员，组合方案完整覆盖仍按 AND 计算。缺测时全量 rate 为 null，同时给出 observed_rate、observed_denominator、missing_case_ids 和确认成功下界。宏平均的 numerator 为逐题分数之和，denominator 为适用题数；微平均单位为 case/fact-group。语义分数可来自披露身份的 AI 复核，只作暂定结果；human_confirmed_task_success_lower_bound 仅计入显式人工审批。

正式独立运行在当前开发入口中明确禁止，报告 conclusion=not_applicable；冻结门槛及正式验收尚未实现。用量无法确认时为 null，即使旧 observer 输出0也不推断已观测到0 token。工具制品采用原始字节 SHA-256，与历史 manifest 的换行归一化哈希分开命名、互不改写。
